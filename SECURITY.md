# Security policy

This repository contains demonstration code. Only the latest main branch is maintained; no response-time commitment is offered.

Do not place credentials, passenger records, customer data or production logs in issues, pull requests or examples. Use synthetic fixtures.

Report vulnerabilities through GitHub private vulnerability reporting if available. Otherwise open an issue requesting a private reporting channel, without exploit details or sensitive data. Do not publish vulnerability details before coordination.

Before business deployment, implement authentication, access controls, secret management, data retention and human approval appropriate to your environment. Never treat a demo approval or local publishing record as a production business action.
