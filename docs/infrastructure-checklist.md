# 工业 Agent 基建选型记录

每个案例评估以下项目，并记录“已使用 / 暂不需要及原因 / 计划 / 未验证”。评估全部层级，不要求安装全部组件。

| 层级 | 应评估的能力 | 候选组件 |
| --- | --- | --- |
| 模型服务 | 接口、并发、超时、模型版本 | Ollama、vLLM、LiteLLM |
| 数据契约 | 校验、兼容、错误格式 | FastAPI、Pydantic、JSON Schema |
| 数据与状态 | 持久化、租户隔离、检查点 | SQLite、PostgreSQL |
| 缓存与文件 | 缓存失效、限流、版本、保留 | Redis、对象存储 |
| 检索 | 元数据过滤、引用、召回评估 | pgvector、Qdrant、全文索引 |
| 异步任务 | 队列、并发、重试、死信 | Celery、消息队列 |
| 工具连接 | 最小权限、输入校验、审计 | MCP、业务 API 适配器 |
| 编排 | 单一编排责任、人工审批 | Dify、n8n、LangChain/LangGraph |
| 部署 | 依赖锁定、配置、健康检查 | Docker Compose、反向代理 |
| 观测与评估 | 轨迹、延迟、成本、回归 | OpenTelemetry、Langfuse、pytest |
| 安全与恢复 | 认证、密钥、审计、备份恢复 | 按环境选择 |

横跨各层：幂等、事务、超时、有限重试、失败恢复、人工审批。没有实际执行证据的组件不得标为已接入。服务依赖和许可证按使用版本核实。
