# 工程记录

核查日期 2026-11-09。五批预期依次为达标、低于要求、到货已到期、缺日期、缺批次记录。阈值是合成演示策略，最短时长含等号，到期时点排除。模型回复与计算报告分别保留。工具错误回传，四轮耗尽或推理失败时 API 返回失败。人审只确认报告。测试定义覆盖阈值、缺证、作用域、重复记录、人工恢复和轮次上限。仅静态检查，测试、模型、平台及课堂脚本未运行。

| 基建 | 选择及原因 |
| --- | --- |
| 模型与接口 | Ollama 本机 chat，支持工具循环，调用超时 120 秒。FastAPI/Pydantic 校验票据。实机待验收 |
| 数据库和状态 | 内存检查点，单 worker，重启后重新提交。生产需持久化、隔离和恢复演练 |
| Redis、限流与队列 | 小型只读演示无需缓存和异步队列。并发忙返回429；批量场景再评估 |
| 对象存储、向量、全文与 RAG | 合成结构化记录，无附件或语义检索 |
| MCP 与业务适配 | 本地只读工具，生产再对接权威批次及客户策略 |
| 编排与部署 | LangGraph 管理循环与人审，n8n 只转发。Dify 和额外 LangChain 层不需要。回环 API，无容器和代理。平台未实机验证 |
| 观测、认证和审计 | 工具轨迹、来源、API 环境变量密钥。生产需身份绑定、密钥轮换和审计留存 |
| 幂等、重试、审批 | 有轮数和超时上限；重复提交可能新建报告，无库存写入。人工审核为报告确认 |
| 备份恢复 | 暂无持久业务状态。生产检查点及批次来源需恢复演练 |

现实的日期标签解释、客户策略版本、预计到货变化及批次证据新鲜度需要权威数据和人工确认。本例使用显式偏移时间和固定策略，未建模这些生产规则。
