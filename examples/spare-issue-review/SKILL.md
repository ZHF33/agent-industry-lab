# 备件数量复核
输入申请编号、核对时点和业务说明。依次确认来源和口径，让模型在三个只读工具中自主选取下一步。核算使用同一申请修订、整数件和合成快照，逐备件保留出退库流水编号。
按净领用差异说明不足、超领和退回超过领出。快照过期、版本不同应单列限制。人工确认单据完整性及记录归属，再审核报告。涉及拆箱换算、其他申请退料、跨仓或实际账务应交业务负责人核查。
