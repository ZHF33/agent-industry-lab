# 工程记录

2026-11-25。独立场景为工位与人员的一对一资格匹配，复用受控循环、API、人审及n8n转发。与shift-coverage-review的时间区间合并不同，本例解决个体候选冲突。样例候选J-01=[OP-A,OP-B]、J-02=[OP-A]、J-03=[]。手推第一次J-01配OP-A；第二次沿交替关系重配为J-01/OP-B和J-02/OP-A，第三岗缺。最大覆盖2：只有两名可用人，且第三岗无可用候选。

只执行静态AST语法、JSON/n8n结构、链接与差异检查、样例手推。测试、模型、课堂示例和平台未执行。测试源码含重配反例、可用SCAN人员补岗、空人员、组合资格、布尔标志、重复ID/资格、完整性、越域与时效边界，以及全部512种3乘3候选图对独立枚举最大值的比较。该枚举检查仅为待运行源码，不能宣称512图测试通过。

合同：同一计划最多8岗、8人，每人最多一岗、每岗最多一人，岗位要求1–8个资格全部满足才建候选边，批准资格可为空。所有标识限1–32个ASCII字母、数字、短横线、下划线。已声明完整且不晚于复核时点的人员快照，年龄恰60秒允许，61秒拒绝；False或非布尔完整声明拒绝。未知资格不自动推断，重复人员或岗位拒绝。只读一次固定快照，同图共用。

算法按岗位及人员编号固定顺序。每次为一个新岗位寻找未占用人员，必要时沿现有归属递归调整；每次搜索的seen人员集合防止循环。只有找到完整增广路径后才沿返回链写内存配对，失败不改现有匹配。最多8次外层搜索、递归深度至多8，约O(JE)，J为岗位数、E为候选关系数；报告含每步调整前后配对。最大数量不保证方案唯一，也不实现岗位权重、最小成本或公平目标。

生产范围：资格仅为合成已批准集合，没有证书有效期、工时、跨计划占用、设备类型限制、独立身份或人事实时接入；60秒时效不是资格有效性的证明。完整声明也不独立证明上游无遗漏。真实派岗还需岗位/劳动与安全规则及班组长确认。输出advice_untrusted与结构化matching_report分开，审核不执行排班写入。
