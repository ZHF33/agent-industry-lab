# 工程记录与验收

2026-10-20：交付源码与静态审查。不执行模型、API、n8n或测试，不启动服务。语法和JSON检查的实际结果记录在本次发布记录；下面测试结果均为预期。

## 验收设计

- `python -m unittest test_tools.py test_graph.py`：预期7个工具测试、3个图控制测试通过。覆盖72小时边界、等价时区、过期和陈旧分别呈现、未来快照、无时区拒绝、越界资产、非法有效区间；图测试覆盖工具→证据→人工恢复、错误工具纠正、持续调用达到轮数上限。
- 模型自主选择工具，读取结果后继续；只有三个工具均成功且建议包含至少一个精确来源ID，才进入人工审核。引用存在检查不证明每句结论正确，仍由人对照报告。
- 四轮模型上限、每消息最多三个工具调用、单次模型120秒；工具参数错误返回模型纠正，网络/畸形响应通过API502失败，不伪造已完成建议。模型重复调用也消耗预算。
- as_of是操作员提供的分析参考时刻，不是不可伪造的服务器时钟。工具计算的临界值不代表行业统一证书策略。签发记录与部署记录为合成行政数据，不含TLS实测。
- API共享密钥、非阻塞单进程锁、忙时429、单worker。检查点仅内存；重启丢失，缺少持久化/保留TTL/租户隔离。reviewer是自报名，不是身份认证证据。
- 顶层版本精确固定；未生成全传递依赖锁或供应链验证报告。n8n JSON为集成源码，未实机导入或执行。未做真实模型工具轨迹或生产验收。

## 逐层选型

| 层级 | 选择、原因与边界 |
| --- | --- |
| 模型服务 | 已写Ollama /api/chat工具调用适配，仅固定本地地址；未实机运行 |
| API契约 | FastAPI/Pydantic严格字段、长度、密钥；有偏移时间在图初始化检查 |
| 数据与状态 | 合成字典、InMemorySaver；无数据库文件，持久化和恢复待扩展 |
| Redis缓存与限流 | 暂不需要小样例缓存；串行锁仅限制单进程并发，不是按用户限流 |
| 对象存储 | 暂不需要，无证书文件与大附件；未来仅接入脱敏元数据 |
| 向量/全文/RAG | 暂不需要，资产ID精确读取结构化证据 |
| 异步队列 | 暂不需要单请求演示；长任务/高并发时需任务ID与队列，当前不承诺交付语义 |
| MCP/业务适配器 | 三个只读函数；无CA、DNS、云平台或真实监控适配器 |
| 编排 | LangGraph为唯一Agent编排；n8n只接收/转发提交和人工审核；Dify和独立LangChain不重复引入 |
| 容器与代理 | 暂不需要本机演示；容器地址手动配置，公网部署另需TLS、代理和身份系统 |
| 观测与评估 | 响应内工具轨迹和有限合成测试源码；未运行评估，不存真实日志 |
| 认证/密钥/审计 | 环境变量共享密钥、比较校验、工具对象范围；不提供多租户RBAC与持久审计 |
| 幂等/超时/重试 | 超时与轮数上限；不自动重试、不执行业务写入；任务提交未做幂等 |
| 人工与恢复 | interrupt/Command恢复源码；审核不触发业务动作。持久备份恢复尚未实现 |
