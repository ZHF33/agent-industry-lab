# GPT Image Prompt Library

## 用途
食品摄影和 AI 生图 prompt 模板。

## 适用场景
面包单品图、门店氛围图、社交平台封面、菜单图。

## 输入
- 食品主体
- 口感关键词
- 构图
- 光线
- 背景
- 比例

## 输出
- 中文 prompt
- 英文 prompt
- negative prompt
- 风格注意事项

## 可嵌入 Dify 的 Prompt 片段
生成食品摄影提示词时，明确主体、切面、质地、光线、镜头角度、背景和道具。避免手部畸形、文字乱码、塑料质感和不真实尺寸。

## 风险说明
EvoLinkAI GPT image prompt library 使用 CC0，但仍要注意第三方商标、人物肖像和平台政策。
