# Frontend Design

## 用途
客户后台、审批页、内容日历和素材表的 UI 设计原则。

## 适用场景
需要把 Agent 输出展示给人工审核人员时。

## 输入
- 用户角色
- 任务频率
- 内容状态
- 审批动作

## 输出
- 信息架构
- 表格字段
- 审批按钮
- 状态标签

## 可嵌入 Dify 的 Prompt 片段
设计运营后台时，优先使用紧凑、可扫描、状态明确的布局。避免营销页式大 hero。审批动作必须清楚区分通过、退回、需要修改。
