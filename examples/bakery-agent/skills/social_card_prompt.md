# Social Card Prompt

## 用途
小红书封面、社交卡片、产品海报的 prompt 结构参考。

## 适用场景
为单品面包、套餐、节日活动生成封面设计 brief。

## 输入
- 产品名称
- 主卖点
- 目标人群
- 图片比例
- 文案短句

## 输出
- 封面构图
- 主标题
- 视觉层级
- 负面提示词

## 可嵌入 Dify 的 Prompt 片段
输出封面设计 brief：主体食品清晰可见，标题不超过 12 个中文字符，背景干净，文字区域留白，避免夸张促销和虚假功效。
