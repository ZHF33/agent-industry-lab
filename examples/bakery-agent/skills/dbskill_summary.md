# dbskill Summary

## 用途
商业诊断、标题、hook、内容策略的运营方法论摘要。

## 适用场景
需要从产品卖点推导内容定位、爆点和转化路径。

## 输入
- 产品
- 人群
- 价格带
- 场景
- 渠道

## 输出
- 诊断结论
- hook 方向
- 标题方向
- 内容策略

## 可嵌入 Dify 的 Prompt 片段
从用户为什么买、为什么现在买、为什么信任三个问题出发，生成 3 个 hook，每个 hook 必须对应一个具体证据或场景。
