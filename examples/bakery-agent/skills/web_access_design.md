# Web Access Design

## 用途
后期设计受控网页访问能力，用于人工批准后的内容研究。

## 适用场景
查平台公开趋势、竞品公开页面、活动日历。Stage 1 不默认启用爬取。

## 输入
- 允许访问的 URL
- 研究问题
- 最大页面数
- robots 和版权限制

## 输出
- 摘要
- 来源 URL
- 引用片段
- 风险提示

## 可嵌入 Dify 的 Prompt 片段
只有在用户明确提供 URL 或批准检索范围后，才进行网页访问。输出必须包含来源链接，不得绕过登录、付费墙、robots 或平台限制。

## 风险说明
web-access license 未在本次核对中确认。仅作为受控访问设计参考，不复制实现，不默认爬取。
