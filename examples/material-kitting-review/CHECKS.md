# 工程记录

2026-11-19。按 BODY、BOLT、SEAL 顺序，每项可支持整件数为 10、9、0，限制物料为 SEAL。目标 10 件对应缺口为 0、1、10。仅把 SEAL 改为 10 后，容量变为 9，BOLT 成为限制物料。再把 BOLT 改为 20，可满足 10 件。缺 SEAL 记录时总容量为空。没有把缺项补为零。

仅静态语法、结构、链接检查及手工推演，测试、模型和平台导入未运行。测试源码覆盖零值、缺项、整件取整、目标封顶、非法计数、越权工具、工具结果回送、轮次耗尽和人审恢复。样例按单工单专属可用件数计算。生产需库存预留、工单并发、质量冻结、替代料、损耗、单位换算和 BOM 生效版本。报告审核接受只记录意见。

| 基建 | 使用及范围 |
| --- | --- |
| 模型接入与推理 | 回环 Ollama Chat 工具调用，每请求网络超时参数为 120 秒。实机未验证。 |
| API 契约 | FastAPI/Pydantic 输入限长、拒绝额外字段及不支持的工单或晚于复核时点的证据。 |
| 数据库与状态 | 单进程内存检查点，重启需重交。上线前需租户隔离和持久状态。 |
| Redis、缓存与限流 | 合成数据直接读，缓存暂不需要。使用单进程忙时拒绝。 |
| 对象存储 | 无附件，暂不需要。 |
| 向量、全文检索与 RAG | 固定范围的BOM 与可用件数按键读取，暂不需要。 |
| 异步队列 | 本地同步演示。生产长推理可改异步并配合有界队列。 |
| MCP 与业务适配器 | 使用本地白名单工具，暂无跨客户端协议需求。生产需受限备料台账适配。 |
| 编排 | LangGraph 管理轮次和待审核状态，n8n 转发 HTTP。Dify 与额外 LangChain Agent 层会重复职责。平台未实机验证。 |
| 容器与代理 | 仅回环单进程，本例直接启动。部署时评估代理超时、TLS 与健康检查。 |
| 观测与评估 | 记录工具名称、参数、结果和轮次。失败回传已保存的工具轨迹。生产需持久指标及独立评估样本。 |
| 认证、密钥与审计 | 本地共享密钥读环境变量，生产需审核者身份绑定、密钥轮换和访问审计。 |
| 幂等、超时与重试 | 无隐式应用重试，提交重发可能产生新线程。人工审核通过同一线程恢复；完成后拒绝再次审核。 |
| 审批与备份恢复 | 只审核报告。内存态不做备份，持久化后需恢复演练。 |
