# 工程记录

2026-11-23。复用既有模型工具循环、API、人审和 n8n 转发骨架，新实现按层选样。快照 A 层3件、B层1件，各要求2件，手推数量 A=2、B=1、总计3，B缺1。具体 A 层编号由公开的 SHA-256 排序定义，本次未执行算法取得编号。测试源码检查分层数、缺额、重排不变、跨层重号拒绝、未知分层拒绝、空总体、布尔配额、协议字节、越域及未来证据；脚本模型检查工具结果反馈、纠错、轮次上限和人审恢复。

仅执行 AST 语法、JSON/n8n 结构、Markdown 链接和 Git 差异静态检查；未运行测试、课堂示例、模型或平台。最多1000件、20层；每层配额1–1000，编号为1–64字符 ASCII。排序约 O(n log n)，空间 O(n)。唯一编号在整批内去重，重复直接拒绝。未配配额的层直接拒绝，配额有而总体缺层则如实缺额。布尔值不接受为整数配额。

排序键为 SHA-256 十六进制分数及料件编号。JSON 数组固定 ensure_ascii=True 与无空白分隔，再 UTF-8 编码；不使用跨进程变化的 hash()。规则版本及种子进入报告。同图只加载一次总体，避免各工具读到不同文件版本。Python 3.11 接口均使用已有参数。

生产边界：清单是可复核的确定性建议，不构成随机抽样标准、统计置信度或质量放行。固定公开种子可能被操纵编号；真实使用应先冻结总体、预先批准种子和方案，评估独立随机源、防择种和抽样标准。本例没有总体内容签名、持久版本、身份绑定或实物定位。算法不把缺额转移到其他层。审核允许接受附缺额报告，接受不等于配额满足，更不等于放行。
