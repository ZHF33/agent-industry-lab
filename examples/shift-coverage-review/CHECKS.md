# 工程检查

2026-11-04。场景为班组长核查固定窗口内多条交班证据的并集。工具给出证据段、缺口和来源。工时认定、调班和通知属于其他业务流程。

| 层级 | 选择与范围 |
| --- | --- |
| 模型接入 | Ollama 工具接口源码，单次超时 120 秒，最多四轮 |
| API | FastAPI、Pydantic 固定字段与 UUID 审核路径 |
| 数据状态 | 合成字典、进程内检查点。持久状态和租户隔离待业务接入 |
| Redis | 固定小样例无需缓存。进程忙时返回 429 |
| 对象存储 | 样例直接内置，无附件 |
| 向量与全文检索 | 按 ID 查快照，RAG 暂不需要 |
| 队列 | 同步小规模审查。高并发接入再评估异步队列 |
| MCP 与适配 | 三个只读 Python 工具，暂无外部业务连接 |
| 编排 | LangGraph 管模型循环及人审，n8n 转发。暂无 Dify 知识运营或额外 LangChain 适配需求 |
| 部署 | 单 worker 回环绑定。容器、代理及生产部署待接入设计 |
| 观测 | 返回工具轨迹与来源。持久观测后端待接入 |
| 认证审计 | 环境 API 密钥，审核者名称由调用方声明。生产身份认证和持久审计待接入 |
| 幂等与重试 | 每次提交新线程。模型预算和超时限制失败范围，业务写入与持久幂等暂无需求 |
| 人工审核 | 审核意见绑定线程中的报告 |
| 备份恢复 | 内存检查点重启丢失。持久恢复和备份待接入 |

四小时窗口预期覆盖 13200 秒、缺口 1200 秒。样例是已结束班次且快照新鲜。来源声明完整与真实记录完整应分别核查。固定直接依赖，传递依赖需随目标平台解析。

检查范围为 AST、JSON、链接、工作流接线及 Git 差异。7 项工具测试和 3 项脚本化图测试为手动验收源码。模型、平台、测试和课堂例子均未执行。

时间处理核查 Python 的带偏移时间对象及 UTC 转换。复用已核查的 Ollama 工具回传与 LangGraph 检查点接口。详见 [datetime](https://docs.python.org/3/library/datetime.html#aware-and-naive-objects)、[Ollama](https://docs.ollama.com/capabilities/tool-calling)、[LangGraph](https://docs.langchain.com/oss/python/langgraph/interrupts)。
