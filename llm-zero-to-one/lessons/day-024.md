# Day024 条件判断

假设车间领料前要查看票据。没有票据就先补，编号不匹配就回查，满足条件才发料。程序中，条件是能求出真假结果的表达式。分支是条件成立后执行的一段代码。类比只说明路径选择，软件还需定义输入类型和失败处理。

## 先检查前提，再计算数值

例如当前次数可以是 0，也可以是 None。None 表示这次没有收到读数。在 Python 中 if 检查真假。写 current is None 可以明确识别缺值，于是零仍有机会参与后续计算。只有证据齐全时才检查 current < previous。比较时，左边必须能与右边比较，None 和整数直接比大小会引发 TypeError。

小题。把 if current is None 写成 if not current 会怎样？这两个表达式对零的结果不同。前者为假，后者为真，会把有效零值当缺证。

## 第一条成立的分支

if 检查首个条件，elif 表示前面未成立时继续检查。else 在此前分支均未执行时处理剩余情况。缩进标明归属。用读数 90 和计划 10 手算，若上限是 100，90+10>100 为假，于是走 else。只将计划改为 11，比较为真，于是走超限分支。

小题。上一读数 88、当前 5 时，能否先按 5+4 判定为可用？若先比较上限，会跳过回退证据。必须先检查数据连续性，才使用当前读数估算。多个独立 if 也可能重复给出结果，而一组 if、elif、else 只走第一条成立的路径。

## 最小实验

准备 Python 3.11+，从仓库根目录运行 [课堂脚本](../examples/day024_conditions_lab.py)。

```powershell
python llm-zero-to-one/examples/day024_conditions_lab.py
```

脚本接受上一读数、当前读数、下批用量、上限。先判缺值，再判回退，再比较预计累计。样例预期打印 fits、exceeds、regression、missing、fits，最后一项把当前读数设为 0，仍能计算。本轮只完成静态检查。若遇缩进报错，核对同级分支是否对齐。若出现类型错误，检查输入是否符合约定。

交一张路径表，把五条输入的第一个成立条件和结果标出来。练习。把超过上限的条件从 > 改成 >=，第一条会怎样？它会改判 exceeds，因为等于 100 已满足新比较式。选择比较符号前应确认业务边界。
