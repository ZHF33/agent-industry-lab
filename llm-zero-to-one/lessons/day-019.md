# Day019 Python 脚本是什么

把备件标签上的数量用同一套规则核算，像照工序卡加工。脚本是装有指令的文本文件。Python 解释器读取它并按规则执行。工序卡的类比止于可重复的步骤。解释器按语法处理，缺输入时不会自行向同事打听。

## 输入、动作、输出

下面三行用于阅读，完整程序见实验。变量是给值起的名字。requested、issued 和 returned 分别代表申请、领出、退回。代码先算净领，再减申请。print 把结果送到屏幕。

```python
net = issued - returned
difference = net - requested
print(difference)
```

纸上推演 10、8、1。先算 7，再得 -3。只把退回改成 0，结果为 -2。换一个输入就能对照一段程序如何处理信息。写一段说明让模型自行算也是一种交互，但工具中的确定性脚本给人工留下可复核的规则。

## 定义函数和调用函数

完整示例把三行计算收进函数 difference。定义时登记函数名和参数，调用时才用输入执行函数体。return 把值交给调用者，调用者可打印，也可用它做后续判断。问题是只写函数定义会看到 -3 吗？不会，因为未发生调用。

脚本入口的判断读取 Python 提供的特殊变量 __name__。直接运行脚本时，它等于 '__main__'，于是调用函数并打印。被另一段代码导入时，变量通常是模块名，示例的打印行不执行。导入仍会执行模块顶层代码，所以将文件写入等动作放在显式入口，避免导入时触发。

## 实验

准备 Python 3.11+，进入仓库根目录，用 PowerShell 运行 [实验脚本](../examples/day019_script_lab.py)。

```powershell
python llm-zero-to-one/examples/day019_script_lab.py
Set-Location llm-zero-to-one/examples
python -c "import day019_script_lab; print(day019_script_lab.difference(10, 8, 0))"
```

第一条预期 -3。最后一条预期只有 -2。第二次刻意改变调用方式和输入，在纸上也可分开验证两件事：仅导入时不会显示示例，退回为零时函数返回 -2。此次只做静态审查，实际输出请自行记录。若提示找不到文件，用 Get-Location 检查路径。IndentationError 指缩进语法问题，NameError 则检查变量是否拼错或未定义。

## 练习与答案

1. 把函数里的 return 改成 print 会发生什么？屏幕先出现内部计算结果，函数返回 None。若外面再 print 一次，就会多打印 None。显示与返回各有用途。
2. 怎样让两次实验只改变一个条件？先两次直接调用，保留申请和实领，仅改变退回。再保留输入，比较直接运行和导入调用的输出。
3. 提交函数的输入、计算式、两个预期值和一条故障修正记录。Agent 中业务工具也可用相同方法逐层检查。脚本运行一次只验证对应输入，其他输入需要另外设计验证。
