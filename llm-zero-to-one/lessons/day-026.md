# Day 026 函数的输入输出

## 一张计件单能做什么

入库员拿到一张计件单，上面写“3 箱，每箱 4 件”。他算出 12 件，交给同事继续加总。如果他只把 12 写到墙上，墙上能看到数字，但同事还得抄回来。程序中同样可以把数字交回调用处，也可以只在屏幕上显示。类比只说明输出去向。程序调用是靠代码传值，显示也可能写到文件或其他输出位置。

学完后，你能解释一段计算接收了哪些值、把结果交给谁，以及少写 return 时下一个步骤会拿到什么。

## 把输入接到计算上

函数是一段可用名字调用的代码。def 定义函数，括号内列出的名字叫参数。实际调用时写进去的值叫实参。在下面的讲解片段中，执行定义会创建函数。调用后，Python 才将 3 和 4 依次绑定到 boxes 和 units_per_box，再计算乘积。

```python
def load_units(boxes, units_per_box):
    return boxes * units_per_box
```

上面是讲解片段，完整实验见下方脚本。return 结束这次调用，将计算值交回调用的位置。对 load_units(3, 4)，返回整数 12，调用者可用变量保存它。若再调用 load_units(1, 4)，这一次参数独立对应 1 和 4，返回 4。加起来是 16。这里约定每箱件数相同，不处理混装、缺箱等业务情况。

**小问题**　只把第一项的箱数 3 改为 4，两个加总步骤会得到什么？

**解释**　第一次返回值从 12 变为 16，第二次仍是 4，加总从 16 变成 20。同一函数可以接收不同参数，每次按那次的值计算。

## 看见数字，和取得数字

对照函数 show_load_units 也算 3 × 4，但把结果交给 print，然后走到函数末尾。Python 对走到末尾的函数返回 None，它表示此处没有返回业务值。None 可以保存在变量里。将它直接和整数相加会触发 TypeError，含义是这种类型组合不能执行加法。即使屏幕上先出现了 12，加总那行拿到的仍是 None。

**小问题**　为什么把两个 print 结果连起来不能当作总件数？

**解释**　打印动作写出文本。数字要参与计算，需要函数返回整数，或另有明确的数据读取与解析步骤。这里直接 return 数字就能接上后续计算。

## 给工具写清输入输出

Agent 工具也需要输入契约，意思是提前写明可接收的参数和范围。出货 Agent 只允许模型提交当前出货单编号。实际读出箱数和容量后，工具返回结构化结果，后续步骤可检查总量字段是否存在。函数定义本身不会自动保证业务参数正确，还要用校验代码限制范围。教程示例也未验证输入来源，负数或含义错位的整数都可能被乘出来。

验收记录包含一个新例子和一个反例。例子：2 箱每箱 6 件与 1 箱每箱 4 件，先得到 12 和 4，再得 16。反例：若 6 的含义其实是每层箱数，乘积 12 对件数没有可用的解释。说明应先核对参数单位，不能凭计算成功认定业务结果成立。
