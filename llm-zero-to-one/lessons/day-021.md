# Day021 数字与布尔值

维修台账上，“还有 3 个零件”回答数量，“有没有零件”回答是或否。Python 中整数用于表达可精确计数的值，浮点数常用于近似测量，布尔值只有 True 和 False 两种。台账类比解释它们的业务含义。程序运行时还需要按接口要求确认类型。

## 从数字得到判断

比较 3 > 0，程序产生 True。把 3 换成 0，产生 False。判断前后的数据不同，输入是数量，输出是问题的答案。整数计数可精确加减。许多十进制小数在二进制浮点中只能近似表示，涉及金额或精确十进制时要按业务要求使用整数单位或 Decimal。

小题。把 0.1 加 0.2 后直接与 0.3 比，为什么可能得到 False？这三个浮点对象存的是邻近二进制值，前两者的和可能与第三个对象的值不同。课堂代码会展示这个具体结果。

## Python 为什么会接收 True

Python 的 bool 是 int 的子类型，所以 isinstance(True, int) 得 True，True + 2 得 3。类型有继承关系，但工单等级的业务规则需要明确的整数值。输入等级 True 时，若只用 isinstance，程序可能把它当成等级 1。写成 type(value) is int，便可明确接受普通整数。对于真实接口，也可以由严格的数据校验器表达这条约定。

小题。0、False、None 能否统一为“没有零件”？不能。0 是确认为零的数量，False 是否定判断，None 可表示尚未取到数据。若用 if not value，这三种都会进入同一分支，导致未知数据被误判。

## 实验与验收

准备 Python 3.11+，从仓库根目录运行 [课堂脚本](../examples/day021_numbers_bool_lab.py)。

```powershell
python llm-zero-to-one/examples/day021_numbers_bool_lab.py
```

脚本依次检查 1、True、0、None。每次先显示对象与整数继承检查，再显示是否是 1 到 3 的有效等级。只有 1 的等级检查为 True。最后一行比较 0.1 + 0.2 和 0.3，预期 False。本次仅静态审查。运行后记录实际结果。若报 TypeError，先核对比较前有没有排除 None 或字符串。

练习。把等级从整数 1 改为字符串 "1"，预期如何？继承检查和等级检查都为 False，文本是否可转换应由接口明确约定。再把等级从 1 改成 4，类型合格但范围不合格。交付一张输入、类型、可接受性和原因的对照表。

返工 Agent 用等级排序并用布尔值记录逾期。模型读取两种字段时，前者用于排序，后者用于表达是否超过承诺时间。
