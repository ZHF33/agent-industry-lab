# 原理教学主线：知识来源与365单元的连接

教学质量标准与现有365单元配套使用。核查：2026-10-20。

本次调整解决的问题：原计划有主题顺序，但部分任务反复使用“写概念卡、画流程图”，不能充分证明理解。后续每课必须回答：为什么需要它、它内部怎样计算、改变条件会怎样、如何知道自己理解对了。框架名称不能代替原理。

## 二、365单元增加贯穿的原理线

保持现有编号和前置顺序。第一轮先建立可口述的因果链；之后重新进入同一概念时增加计算、实验和工程判断，不把“讲过术语”当成“已经学会”。下面为各阶段的补强要求，不声称365篇正文已经完成。

| 对应单元 | 原理链 | 要能解释的因果关系 | 可检查的学习证据 |
| --- | --- | --- | --- |
| 001–030 | 文本→词元→编号→向量→上下文计算→分数→概率→选下一片段 | 为什么生成流畅不保证真实；聊天保存不等于改参数 | 手工走一轮生成，指出分词与编号、概率与置信度的区别 |
| 031–060 | 表示、数据类型、控制流、函数与异常 | 为什么字符串“12”和数字12可能产生不同结果；为什么错误不能静默吞掉 | 预测代码输出，再解释一个失败输入；分清预期与实测 |
| 061–090 | 条件生成、少样本、温度、输出约束 | 提示改变条件，采样改变选择方式；JSON合法不等于字段真实 | 对比两个提示的假设；按人工分数计算温度变化；校验错误字段 |
| 091–120 | 向量、矩阵、点积、softmax、交叉熵、梯度、注意力 | 相似度怎么计算；损失如何给学习信号；遮罩为什么防止偷看未来 | 手算二维向量、三项softmax和单步损失；画出允许读取的位置 |
| 121–150 | 文档分块、倒排索引、TF-IDF/BM25、嵌入与近邻 | 关键词匹配与语义匹配各解决什么；分块如何丢失条件 | 同一否定条件跨块前后，比较检索内容；保留原文定位 |
| 151–180 | 召回、重排、证据拼接与生成 | 找到资料、找到正确资料、正确引用资料是三件事 | 分开测检索召回、证据支持与回答正确；加入无答案题 |
| 181–210 | 请求响应、状态、并发、流式传输与取消 | 页面显示一段文字为何不代表任务完成；重试为何可能重复执行 | 画一次失败重试；区分请求ID、任务ID和业务幂等键 |
| 211–240 | 状态机、模型决策、工具执行、观察结果与停止 | 工作流与Agent的差别；为什么模型请求调用不等于获准执行 | 手推工具失败、参数错误、达轮数上限和人工拒绝四种路径 |
| 241–270 | 数据分布、监督学习、泛化、过拟合、LoRA | 训练损失低为何未必好；为何只训练少量参数也可改变行为 | 对比训练集/留出集；手算低秩矩阵尺寸与可训练参数量 |
| 271–300 | 偏好目标、奖励、量化、KV缓存与计算开销 | 人偏好不等于事实；缓存为何省重复计算却占内存 | 构造“好听但错误”的偏好反例；估算权重与缓存内存并写假设 |
| 301–330 | 测量、抽样、数据泄漏、权限与反馈 | 指标为什么可能失真；模型自评为什么不能独立证明正确 | 设计错例集、盲测与权限越界用例；解释误报/漏报 |
| 331–360 | 模态编码、表示对齐、时序与跨模态证据 | 图片进入模型前发生什么；识别到文字为何未必理解画面 | 标注一个图文冲突案例，定位错误来自识别、检索还是推断 |
| 361–365 | 假设、证据、可复现性与交付边界 | demo成功与稳定服务之间缺什么 | 交付有来源、有对照、有失败路径的作品说明 |

数学必须有台阶：先讲生活问题，再解释一个小数字例子，最后引入符号。公式出现时逐一解释符号、输入、输出、适用前提。前期不给尚未介绍的矩阵运算当作必做题；后期也不能一直用类比替代真实计算。

## 三、每课固定的质量门槛

1. **知识目标**：一句话说明学完能解释哪条因果关系，不能只写“了解某工具”。
2. **来源到段落**：列本次确实读到的章节，并说明使用了哪个知识点；选题目录与已读正文分开。
3. **问题与反例**：先解释旧方法哪里不够，再引入新方法；必须有会失败的条件。
4. **机制与表示**：指出输入如何表示、怎样变换、输出意味着什么。
5. **推演或对照实验**：只改变一个条件，先预测再观察；未执行的只写预期结果。
6. **小白讲解**：新术语中文释义、类比边界、必要前置、逐步答案；不以堆公式代替解释。
7. **工程连接**：说明该概念在仓库项目的哪一步有用，不要求每课装框架。
8. **验收**：让读者解释一个新例子，或判断一个错误说法；只复述定义不算通过。

## 四、需要纠正的参考表述

- Universe C2把低温度与规避幻觉联系得过强。温度调节分布的集中程度，不能把错误知识变成正确知识，零温度也不构成跨平台完全复现保证。
- Cookbook提示原则把分隔符描述为可防提示注入。分隔符能帮助区分内容，但不是权限隔离；工具权限、服务端校验和数据访问控制仍需程序实现。
- 提示里的“给时间思考”应教学为任务拆解、必要计算和结果核对；仅等待几秒或让回答更长不自动增加可靠性。
- “大模型”不设统一参数门槛；不能把某历史大模型的参数量当成概念定义。

这些是本课程基于机制做出的校正，不意味着上游所有代码都已逐一审查。
