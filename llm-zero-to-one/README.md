# 从零到一学大模型

**零基础中文课程 · 365个学习单元 · 从理解模型到交付应用。**

[开始第一期](lessons/day-001.md) · [365天教学计划](PLAN-365.md) · [资料拆解与来源](SOURCES.md) · [课程数据](curriculum.json) · [原理主线与来源映射](PRINCIPLES-AND-SOURCE-MAP.md)

## 每天怎么学

建议30–60分钟，难度较高时可拆开复习：读场景与原理、手工推演、完成练习、对照解释性答案，再记录不理解的地方。每一期包含前置条件、术语、反例、最小实验或可推演案例、预期输出、常见错误和来源。无GPU路线优先；不默认下载模型、启动服务或购买算力。
