# 从零到一学大模型 · 365天教学计划

Day是学习单元编号，不绑定自然日期；按顺序每天推进一单元，困难内容允许复习和顺延。规划365个单元不代表365篇正文已完成。每日产出为概念/流程/推演/最小实现/验收之一，正文仍须完整教学。

参考标签：[U：LLM Universe](https://github.com/datawhalechina/llm-universe) · [C：LLM Cookbook](https://github.com/datawhalechina/llm-cookbook) · [F/E：LLM Course基础与科学家/工程路线](https://github.com/mlabonne/llm-course)。这些是主题参考，不是上游为本课程逐日编排或背书。

基础路线先做应用再理解训练；数学与训练单元有无GPU替代任务，不要求购买算力。前一日练习是后一日准备，每30单元交一个阶段作品；最后5单元做交付审核。
