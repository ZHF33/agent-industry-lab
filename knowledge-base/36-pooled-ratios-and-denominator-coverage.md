# 第36讲 汇总比率与分母覆盖

## 两家店的退货率能直接平均吗

街角小店卖了 10 件，退了 5 件。仓库店卖了 90 件，退了 0 件。你问哪家店更容易出现退货，两家店的比率各有意义。你问这 100 件里有多少件退货，得按商品数合计，答案是 5%。把 50% 和 0% 平均得到 25%，回答的是把两家店当作同等权重的问题。工厂每件产品能否纳入统计，还要看返工、重复检验和窗口划分。这些口径需查台账。

**小问题**　如果两店各卖 10 件，退货率仍为 50% 和 0%，总体退货率是多少？

**解释**　5 件退货除以 20 件售出，得 25%。两家的分母相同，此时等权平均恰好等于按件汇总。

## 从各线计数推到汇总

分子是要数的事件数，分母是符合纳入口径的总数。对一次检验合格率，记第 i 条产线的一次通过数为 Pᵢ，首次被检的不同产品数为 Nᵢ。记 P 为所有 Pᵢ 的和，N 为所有 Nᵢ 的和。只要各线记录齐全、产品不重叠、且 N 大于零，按件合格率就是 P/N。对 Nᵢ 大于零的行，也可将各线比率 Pᵢ/Nᵢ 乘以各自权重 Nᵢ/N，再把这些加权结果相加。相乘约掉 Nᵢ，每项留下 Pᵢ/N，合计便回到 P/N。

A 线合格 90/90，B 线 5/10，C 线确认 0/0。A 权重 90/100，B 权重 10/100。合计为 95/100。C 线的单线合格率无定义，已确认的零检验对两个总数均贡献零。总体 95% 可和 B 线 50% 同时成立，两个比率回答的范围不同。

如果门槛为 95%，可用 9500 个基点表示。一个基点为 0.01 个百分点。对正分母，比较 P/N ≥ 9500/10000 等价于比较 P × 10000 ≥ 9500 × N。上例两边均为 950000。把门槛提高一个基点，右边变为 950100，未达到。整数比较避免先将一个略低于门槛的百分比四舍五入为门槛值。

**小问题**　C 线没有发送数据，还能说整体正好 95% 吗？

**解释**　此时只知道报告到达的两条线是 95/100。若 C 实际为 0/10，总体成了 95/110。先枚举应到记录，再决定能否发布汇总。明确的零检验记录与缺记录表达不同事实。

## 实验

准备 Python 3.11 或更新版本。打开终端，切换到仓库根目录，执行下列命令。此脚本使用标准库和合成数据。

```powershell
python knowledge-base/examples/pooled_ratio_lab.py
```

[课堂脚本](examples/pooled_ratio_lab.py)接收按预期产线排列的列表。每项是一对整数（通过数、检验数），或代表缺行的 None。先检查 None，再分别加总。这样缺行直接产出缺证状态。若检验总数为零，返回空比率。最后将两个整数作为参数交给 Fraction，保存精确分数，其显示会约分。工程报告另外保留原始的 95 和 100，以便看出证据规模。

预期输出如下。本次只静态检查及手推，未执行脚本。

```text
closed: ready 19/20
missing: missing_line None
empty: no_inspections None
```

若终端显示找不到文件，先检查工作目录。若第三行出现除零异常，核对零分母分支是否放在构造分数前。把第二组 None 改成 (0, 0)，预期第二行变成 ready 19/20。这是声明窗口内 C 线零检验，实际业务中需要来源证明。

## 工程取舍与练习

先做窗口、预期产线和计数校验，再计算比率。按线等权可以回答“平均一条线表现如何”，按件汇总回答“随机从这批被检件中取一件，通过比例是多少”。两者都可能掩盖低表现分组，日报应带逐线规模和结果。追踪多个窗口时保存原始计数和互斥范围，后续合并仍应加总计数。

[产线一次检验合格率复核 Agent](../examples/first-pass-yield-review/README.md) 增加整型、范围、封账时间和预期产线检查，并将依据送回模型供解释。当前证据由本地合成计数构成。逐件去重、返工排除和跨线转移的归属仍需质量系统提供。若 A 线 2/2、B 线 4/8，逐线平均与总体各是多少？答案是 (100% + 50%)/2 = 75%，按件合计 6/10 = 60%。若 B 线变成过去另一个窗口的 4/8，两项应分开核对，分数公式无法修复窗口错配。
