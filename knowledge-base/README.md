## 学习方向

服务与契约 → 数据与状态 → 模型服务 → 工具连接 → 文档与知识 → RAG → Agent 编排 → 业务工作流 → 异步与可靠性 → 运行部署 → 观测安全 → 综合工程。

每天推进一个有独立学习目标的课程内容；主题可继续深入，不按篇数凑内容。代码与 Agent/Skill 实战共用，平台、模型、离线和生产验证分别标记。

## 每篇课程

业务问题与反例 → 核心机制 → 代码逐步解释 → 可复现实验 → 故障排查 → 方案取舍 → 课堂练习与参考答案 → 官方资料。

准备条件、命令、预期和实际结果、验证限制必须明确。草稿供审阅后再发布；示例仅使用合成数据，不自动调用付费服务。原创课程及代码遵循 MIT，第三方软件和材料保留各自许可。
